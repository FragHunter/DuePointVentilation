# HX-V1 exported CAD

Versioned CAD export for the current HX-V1 regenerative pendulum prototype.

Files:

- `HX-V1-core.step` — editable/interchange CAD for the regenerative core
- `HX-V1-core.stl` — printable mesh for the regenerative core
- `HX-V1-module-shell.step` — editable/interchange CAD for the first module shell
- `HX-V1-module-shell.stl` — printable mesh for the first module shell
- `HX-V1-metadata.json` — generated dimensions and design metadata
- `SHA256SUMS` — checksums for artifact verification

These files are generated from the parameterized CadQuery source in `cad/heat-exchanger/` and are development artifacts, not yet production-ready parts.
