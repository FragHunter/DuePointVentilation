# HX-V1.1 CAD exports

Versioned generated exports for the HX-V1.1 regenerative pendulum module.

Included STEP/STL pairs:

- complete assembly (reference/visualization; not intended as one-piece Mega S print),
- regenerative core,
- core sleeve,
- room plenum,
- outside plenum with drain,
- compressed gasket model.

HX-V1.1-metadata.json contains the generated geometry/design values.

Review section images are stored in ../../review/HX-V1.1/.
Simulation data and plots are stored in ../../simulation/HX-V1.1/.
