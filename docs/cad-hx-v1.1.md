# HX-V1.1 mechanical design

HX-V1.1 is the first serviceable revision of the two-room regenerative pendulum module.

It fixes the main HX-V1 serviceability error: the 120 x 120 mm core is no longer trapped behind a 112 mm integral fan opening.

## Assembly

Room fan -> room plenum -> gasket/bolted interface -> open-ended core sleeve with removable regenerative matrix -> gasket/bolted interface -> outside plenum with drain -> outside fan.

The two plenums are removable. The core slides through the open sleeve before the plenums are attached.

## Current geometry

- core: 120 x 120 x 160 mm
- 18 x 18 channels
- internal wall: 0.8 mm
- perimeter handling/sealing frame: 3.2 mm
- nominal side clearance: 0.8 mm per side
- nominal gasket: 1.0 mm
- modeled compressed gasket: 0.8 mm
- target gasket compression: 20 percent
- sleeve: about 146 x 146 x 161.6 mm including interfaces
- square-to-round plenum length: 45 mm
- fan opening: 112 mm diameter
- fan mount spacing model: 105 mm
- drain bore: 8 mm
- intended installation slope: 2 degrees outward

## Improvements over HX-V1

- serviceable open-ended sleeve,
- removable plenum interfaces,
- cartridge retention by the plenum-side flange,
- gasket compression strategy,
- larger FDM clearance,
- reinforced core perimeter,
- print-width-aligned 0.8 mm matrix walls,
- smooth square-to-round transition,
- outside condensate drain,
- individual parts sized for Anycubic i3 Mega S.

## Still provisional

The current axial opposed-fan routing is retained as a benchmark, not yet selected as the final architecture.
